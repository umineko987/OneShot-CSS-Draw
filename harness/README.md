# OneShot Web 控制台

本地 Web 界面，用于配置渠道、启动测试和查看运行结果。配置与测试操作均在 UI 内进行。

## 环境准备

- Node.js **22.19.0 或更高版本**、npm 和 bash。
- 浏览器。
- 包含 `harness/` 和参考图的完整项目目录，保留原有目录结构。

> 本地凭据、个人配置与依赖目录不随仓库分发。首次部署无需预先填写配置文件，启动后在 UI 内配置即可。

## 部署与启动

以下命令均在**项目根目录**执行，不是在 `harness/` 内执行：

```bash
npm --prefix harness ci --ignore-scripts
npm --prefix harness run ui
```

无需前端构建。启动成功后，在浏览器打开终端输出的地址，默认是：

**http://127.0.0.1:4311**

保持终端运行，后续渠道配置、鉴权、测试和观测都在页面内完成。启动控制台本身不会调用模型。

之后再次启动时，只需执行：

```bash
npm --prefix harness run ui
```

## 端口占用

如果默认端口被占用，可以自动选择空闲端口：

```bash
npm --prefix harness run ui -- --port 0
```

请打开**终端实际输出的地址**，不要继续访问被其他程序占用的端口。

## 停止服务

在启动服务的终端按 **Ctrl+C**。这会中断该服务启动的任务和登录流程；仅关闭浏览器页面不会停止服务或任务。

控制台仅监听 `127.0.0.1`，供可信本机使用，不要暴露公网或配置反向代理。
